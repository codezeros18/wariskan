Wariskan menggunakan kombinasi tools berikut: OpenAI (`gpt-4o-mini-transcribe`) untuk speech-to-text Bahasa Indonesia dari voice note user, Anthropic Claude Sonnet 4 (`claude-sonnet-4-20250514`) sebagai reasoning engine untuk ekstraksi entitas transaksi ke JSON terstruktur dan sebagai primary vision model untuk OCR foto nota/struk, dengan fallback ke `claude-3-5-haiku-20241022` untuk text extraction jika model utama tidak tersedia. Seluruh workflow diorkestrasi oleh n8n dengan native cron scheduler untuk reminder hutang harian (09:00 WIB) dan weekly report otomatis (Minggu 20:00 WIB). Pada integration layer, kami menggunakan WAHA (WhatsApp HTTP API, self-hosted via Docker) sebagai gateway ke WhatsApp dengan owner-only reply mode, Google Sheets API (diakses via Helper API di localhost:3001) sebagai per-user ledger dengan auto-create sheet untuk user baru, dan Supabase (PostgreSQL) untuk state management dengan tabel: users, transactions, incoming_messages, outgoing_messages, reminders, weekly_reports. Infrastructure: n8n dan Helper API berjalan lokal (target deploy ke Railway), Supabase Cloud untuk database, dan GitHub untuk version control.
